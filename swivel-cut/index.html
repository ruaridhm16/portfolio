SwivelCut Simulator

GitHub

A modular cardboard cutting tool for Design & Technology students, developed from user research through to a resolved final design. A two-link arm swivels to guide a blade along any path within its reach, cutting shapes and templates without a fixed guide or knife.

This is a live model of that motion: draw a path and the simulator solves the inverse kinematics for both joints, compensating for the blade's own offset from the arm's pivot so the cut follows the line you actually drew.

Blade: UP
Shoulder: 0.0°
Elbow: 180.0°
Stabilise: Off
